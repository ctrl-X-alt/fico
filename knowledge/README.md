# Friction Diagnostic Knowledge Base

Production diagnostic knowledge is versioned separately from code. Retrieved material informs reasoning; it never overrides core safety, schema, evidence, or causal-language rules.

## Structure
- definitions: onboarding, activation, drop-off, friction
- evidence: funnel, screenshots, data quality, measurement windows
- scenarios: normal attrition, optional setup, delayed activation, technical failure, segmentation, qualification, seasonality, conflicting evidence
- diagnostic_rules: evidence, hypotheses, causal language, confidence
- recommendations: onboarding patterns and validation methods
